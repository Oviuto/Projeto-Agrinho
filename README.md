# ☕ Café no Paraná - Agrinho 2026

Projeto desenvolvido para o Agrinho 2026 com o tema:  

**"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"**  

Este site apresenta a importância do café no estado do Paraná, sua história, produção e a relação com a sustentabilidade.

---

## 🌱 Sobre o projeto

O site é uma **página única com scroll vertical**, dividida em repartições que abordam:

- 🌄 Introdução sobre o café no Paraná  
- 📜 História da cafeicultura no estado  
- 🚜 Produção atual e tecnologia no campo  
- 🌎 Sustentabilidade e preservação ambiental  
- 🧾 Rodapé com créditos  

O objetivo é mostrar como a agricultura pode se desenvolver de forma **sustentável**, equilibrando produção agrícola com respeito ao meio ambiente.

---
